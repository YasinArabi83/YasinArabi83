# میز کار برنامه‌نویس — رزومهٔ تعاملی سه‌بعدی

## مفهوم

به‌جای اشکال انتزاعی، صحنهٔ سه‌بعدی یک **میز کار واقعی برنامه‌نویس** است: اتاقی ایزومتریک با میز چوبی، مانیتور دوتایی (صفحهٔ اصلی کد C# را زنده تایپ می‌کند و صفحهٔ دوم به‌صورت متناوب بین داشبورد پروژه‌ها و ترمینال جابه‌جا می‌شود)، کیبورد مکانیکال با کلیدهای RGB، کیس با فن چرخان، کتابخانهٔ دیواری، چراغ مطالعهٔ گرم، فنجان چای با بخار، مرغابی دیباگ و صندلی گیمینگ.

## معماری

- **Three.js (r170)** — تمام هندسه‌ها رویه‌ای (بدون مدل خارجی)، بافت‌ها با `CanvasTexture` (کد/ترمینال/داشبورد/پوستر/پنجره)
- **وب خالص** — ES Modules، بدون build، بدون فریم‌ورک؛ `index.html` + `assets/`
- **رزومهٔ مسطح همیشه در دسترس** — تمام محتوای رزومه به‌صورت HTML معنایی زیر صحنه؛ بدون جاوااسکریپت هم کامل خوانا (پیشرفت‌گرا)
- **RTL فارسی** — فونت وزیرمتن (محلی)، تم تیرهٔ IDE با لهجهٔ سبز ترمینال
- **دسترس‌پذیری** — skip-link، aria-label، `prefers-reduced-motion`، فوکوس‌پذیری نقاط داغ، fallback تصویری برای WebGL

## نقاط داغ (Hotspot)

| شیء | بخش رزومه |
|---|---|
| مانیتور اصلی (کد) | دربارهٔ من |
| کیبورد | مهارت‌ها |
| کیس کامپیوتر | تجربهٔ کاری |
| مانیتور دوم (داشبورد) | پروژه‌ها |
| کتابخانه | تحصیلات |
| فنجان چای | تماس |

## اجرای محلی

```bash
python3 -m http.server 8000
```

ساختار فایل‌ها: `index.html` · `assets/css/main.css` · `assets/js/{data,scene,ui,main}.js` · `assets/vendor/three.module.js` · `assets/fonts/`
