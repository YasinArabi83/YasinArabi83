# شب‌باغ کُد — رزومه سه‌بعدی یاسین عربی

وب‌سایت رزومه استاتیک، همه‌جانبه و تعاملی برای **یاسین عربی** — برنامه‌نویس .NET با تمرکز بر توسعه سامانه‌های سازمانی (ERP).

## مفهوم طراحی

**«شب‌باغ کُد»** — یک باغ ایرانی در شب: سکوهای شناور به شکل **ستاره هشت‌پر** که با **ریسه چراغ** به هم وصل شده‌اند، زیر آسمان گرگ‌ومیش با ستاره‌های چشمک‌زن. هر سکو یک ایستگاه از رزومه است:

| ایستگاه | شیء نمادین سه‌بعدی |
|---|---|
| خانه | مدالیون ستاره گِرِه با مدارها |
| تجربه | مونولیت .NET با ۱۱ مکعب مداری (۱۱ ماژول مهاجرت‌یافته) |
| مهارت‌ها | هسته و بلورهای مداری در سه حلقه |
| پروژه‌ها | قاب‌های شناور پروژه‌ها |
| تحصیلات | ستون کتاب‌ها و حلقه‌های رشد |
| تماس | فانوس، هواپیمای کاغذی و حلقه‌های سیگنال |

## دو حالت نمایش

- **نمای شب** — تجربه سه‌بعدی کامل با پرواز دوربین بین ایستگاه‌ها (Three.js)
- **نمای روز** — رزومه تمیز، سبک و **قابل چاپ** که مستقیماً در HTML ایستا حضور دارد و **حتی بدون جاوااسکریپت هم** کار می‌کند

کارفرما یا بازرس سایت بدون هیچ تعاملی با 3D می‌تواند از همان لحظه اول «نمای روز» را انتخاب کند (دکمه در صفحه بارگذاری، هدر، فوتر و نشانی `#resume`).

## ویژگی‌ها

- **کاملاً راست‌چین (RTL)** و فارسی با فونت وزیرمتن (۵ وزن، میزبانی محلی)
- **بدون build step و بدون CDN** — Three.js به‌صورت vendored در `assets/vendor/` (مناسب دسترسی اینترنت ایران)
- **بدون هیچ فایل مدل یا تصویر** — تمام هندسه و بافت‌ها procedural (Canvas + geometry)
- مسیریابی hash برای هر ایستگاه (`#home`، `#skills`، … و `#resume`)
- ناوبری: منو، دکمه‌ها، کلیدهای جهت‌دار (RTL)، اسکرول، سوایپ لمسی و **کلیک روی خود سکوها**
- دسترس‌پذیری: skip-link، مدیریت فوکوس، `prefers-reduced-motion`، فالبک بدون WebGL (نمای روز)، متن به‌صورت DOM واقعی (قابل انتخاب/جستجو/اسکرین‌ریدر)
- کارایی: سقف pixel ratio (۲ دسکتاپ / ۱.۵ موبایل)، کاهش ذرات و نورپردازی در موبایل، توقف رندر هنگام مخفی بودن تب، پیشرفت پرواز دوربین مستقل از نرخ فریم
- سئو: متا تگ‌ها، Open Graph، JSON-LD (Schema.org Person)

## ساختار پروژه

```
├── index.html               ← محتوای کامل رزومه (تک‌منبع؛ پنل‌های نمای شب از همین بخش‌ها clone می‌شوند)
├── assets/
│   ├── css/main.css         ← توکن‌های طراحی + حالت شب/روز + استایل چاپ
│   ├── js/
│   │   ├── main.js          ← بوت، تشخیص محیط، مدیریت حالت شب/روز
│   │   ├── data.js          ← پیکربندی ایستگاه‌ها و پالت
│   │   ├── scene.js         ← موتور صحنه، آسمان، ستاره‌ها، ریسه چراغ‌ها
│   │   ├── stations.js      ← سکوها و اشیای نمادین (procedural)
│   │   ├── camera.js        ← دوربین‌ران (پرواز، پارالاکس)
│   │   └── ui.js            ← ناوبری، پنل، توست، کیبورد/اسکرول/سوایپ
│   ├── vendor/three.module.js  ← Three.js r170 (vendored)
│   ├── fonts/               ← وزیرمتن (OFL) — متن لایسنس موجود است
│   └── resume-yasin-arabi.pdf  ← نسخه PDF رزومه
└── docs/resume-site.md      ← همین فایل
```

## ویرایش محتوا

تمام متن‌های رزومه فقط در `index.html` (بخش‌های `sec-*` داخل `#dayview`) ویرایش می‌شوند؛ پنل‌های نمای شب به‌صورت خودکار همان محتوا را نمایش می‌دهند. چیدمان صحنه (موقعیت سکوها، دوربین‌ها، رنگ‌ها) در `assets/js/data.js` است.

## اجرای محلی

بدون نصب و build:

```bash
python3 -m http.server 8000
# سپس: http://localhost:8000
```

یا مستقیماً فایل `index.html` را در مرورگر باز کنید (اسکیمای `file://` هم کار می‌کند).

## انتشار

فشار به شاخه `master` کافی است — GitHub Pages از ریشه همین شاخه سرو می‌شود.
