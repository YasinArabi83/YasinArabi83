## ✨ ویژگی‌های طراحی

- **دیزاین سه‌بعدی خلاقانه** بدون هیچ کتابخانه خارجی (Three.js و مشابه آن استفاده نشده):
  - مکعب چرخان مهارت‌ها در بخش Hero که با **درگ ماوس یا لمس** قابل چرخش است (با اینرسی)
  - کارت‌های **tilt** سه‌بعدی که با حرکت ماوس می‌چرخند
  - **کارت ویزیت دو رو** که با hover (یا لمس) flip می‌شود و اطلاعات تماس را نشان می‌دهد
  - پس‌زمینه **ذرات متصل سه‌بعدی** که به حرکت ماوس واکنش نشان می‌دهد
  - زمین شبکه‌ای (Grid Floor) با پرسپکتیو و چرخش مدارهای چیپ‌ها
- **کاملاً راست‌چین (RTL)** با فونت وزیرمتن (بسته‌بندی‌شده به‌صورت لوکال)
- **ریسپانسیو کامل** — موبایل، تبلت و دسکتاپ
- **دسترس‌پذیری (a11y)**: skip-link، aria-label‌ها، کنتراست مناسب، پشتیبانی `prefers-reduced-motion`
- **بدون هیچ وابستگی**: فقط HTML، CSS و JavaScript خالص — بدون CDN و بدون build step
- سئو: متا تگ‌ها، Open Graph و داده ساختاریافته Schema.org (JSON-LD)
- امکان **دانلود رزومه PDF** از داخل سایت

## 🚀 اجرا به‌صورت لوکال

هیچ build یا نصب وابستگی لازم نیست. فایل‌ها را باز کنید و index.html را در مرورگر باز کنید:

```bash
# یا برای حالت واقعی HTTP (اختیاری):
python3 -m http.server 8000
# سپس: http://localhost:8000
```

## 🛠 اصول برنامه‌نویسی رعایت‌شده

- **جداسازی کامل مسؤولیت‌ها**: HTML (محتوا) / CSS (ظاهر) / JS (رفتار) هر کدام فایل جدا.
- **معنایی بودن HTML**: `header`, `nav`, `main`, `section`, `article`, `figure`, `footer`, استفاده از ARIA فقط در صورت نیاز.
- **ماژولار بودن JS**: هر قابلیت یک ماژول مستقل داخل یک IIFE — بدون آلوده کردن global scope (`SpaceCanvas`, `Tilt`, `Cube3D`, `Bizcard`, `Reveal`, `Nav`, `Taglines`).
- **CSS متغیرمحور**: طراحی با CSS Custom Properties (توکن‌های رنگ، فاصله، سایه) — تغییر تم با ویرایش چند خط.
- **کارایی**: `requestAnimationFrame` به‌جای setInterval برای انیمیشن‌ها، رویدادهای `passive`, `will-change` هدفمند، توقف انیمیشن در `prefers-reduced-motion`.
- **دسترس‌پذیری**: ناوبری کیبورد، لینک skip، `aria-expanded/aria-controls/aria-label`، کنتراست رنگ مطابق WCAG.
- **سازگاری**: بدون ES6+ syntax اجباری (متغیرهای `var`، بدون Arrow Function در کدهای پایدار) — کار روی مرورگرهای قدیمی‌تر نیز ممکن است.
